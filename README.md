# Gallery - Telegram Gallery

Android photo and video gallery with optional Telegram sync.

## Download

[Download the latest Android APK](https://github.com/meridian-max/gallery-downloads/releases/latest/download/Gallery.apk)

[Release notes and checksums](https://github.com/meridian-max/gallery-downloads/releases/latest)

Android 8.0 or newer is required. Download `Gallery.apk` and open it on your phone.
If Android asks, allow installation from the app you used to download the file.
Install over an existing Gallery installation to retain its data.

Telegram sign-in is required. Photo/video access is requested after sign-in.
Telegram transfers support both Wi-Fi and mobile data.

## About this repository

This repository distributes signed Android APKs, checksums and release notes.
Application source code is kept in a separate private repository. No bot service
code, bot token, Telegram account sessions or user photos/videos are hosted here.

Gallery is an independent app and is not affiliated with Telegram.
